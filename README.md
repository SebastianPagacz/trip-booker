### trip booker - aplikacja internetowa do rezerwowania jedniodniowych wycieczek
#### Wymagania:
- Administrator moze dodac atrakcje/wycieczke oraz ja customizowac
- Administrator moze zarzadzac istniejaca wycieczka (wylaczac w konkretne dni tygodnia, daty itp.) Admin musi zadecydowac co dzieje sie z zarezerwowanymi wycieczkami na ten dzien
- Klient moze zarezerwowac wycieczke najpozniej N godzin przed jej startem (administrator ustawia globalnie oraz dla wycieczki, by default wchodzi walidacja globalna)
- Klient moze odwolac rezerwacje najpozniej N godzin przed jej startem (administrator ustawia globalnie oraz dla wycieczki, by default wchodzi walidacja globalna)
- Administaror moze dodac rezerwacje recznie, rezerwacja nie moze przekorczyc limtu pasazerow
- Klient moze zalozyc konto i zarzadzac zakupami przy jego uzyciu
