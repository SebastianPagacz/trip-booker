### trip booker - aplikacja internetowa do rezerwowania jedniodniowych wycieczek
#### Wymagania:
- Administrator moze dodac atrakcje/wycieczke oraz ja customizowac
- Administrator moze zarzadzac istniejaca wycieczka (wylaczac w konkretne dni tygodnia, daty itp.)
- Klient moze zarezerwowac wycieczke maksymalnie N godzin przed jej startem (administrator ustawia globalnie oraz dla wycieczki, by default wchodzi walidacja globalna)
- Administaror moze dodac rezerwacje recznie
- Klient moze odwolac rezerwacje maksymalnie N godzin przed jej startem (administrator ustawia globalnie oraz dla wycieczki, by default wchodzi walidacja globalna)
